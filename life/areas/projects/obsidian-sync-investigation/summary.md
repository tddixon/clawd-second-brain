### General

- Obsidian Sync is a GUI-only feature requiring the desktop app to be running. No official headless sync CLI available for triggering sync without display. (01/29/2026)
- Evaluated Yakitrak's obsidian-cli (GitHub: Yakitrak/obsidian-cli). Supports note operations (create, update, delete, search) but does NOT support sync. Requires Obsidian desktop app running for sync to function. (01/29/2026)
- Identified alternatives to Obsidian Sync for headless/terminal sync: (1) Obsidian Git plugin - syncs vault to GitHub, (2) iCloud, Dropbox, or Syncthing - third-party sync for vault folder, (3) Syncthing or Resilio Sync - dedicated sync tools for background file sync. (01/29/2026)
