# SEO Content Employee Framework

**Purpose:** AI employee that takes a website URL/topic and produces complete SEO strategy + written content.

## What This Builds

A GSD-based workflow system that:

1. **Input:** Website URL or topic/context
2. **Outputs:**
   - 15-20+ keyword recommendations
   - Content ideas and topics
   - Site audit with improvements
   - **Fully written, human-sounding articles** (ready to publish)
