## Content Production Workflow

### Phase 1: Research (30-45 min per article)
1. **Keyword research** - Already done (Phase 2)
2. **Competitor analysis:**
   - Google target keyword
   - Open top 5 results
   - Note: Word count, structure, topics covered, gaps
3. **Create outline:**
   - Beat competitor content (more comprehensive)
   - Add unique angles (your insider knowledge)
   - Include sections competitors miss

### Phase 2: Writing (2-3 hours per article)
1. **Draft in Google Docs** or markdown
2. **Write sections in order:**
   - Intro with target keyword
   - Main sections (H2s)
   - FAQ section
   - Conclusion with CTA
3. **Add elements:**
   - Bullet lists (scannability)
   - Tables (featured snippets)
   - Bold key phrases
   - Personal touches (stories, opinions)
4. **Hit word count target** (1,500-3,000 depending on article)

### Phase 3: Humanization (30-45 min per article) **MANDATORY**
1. **Run through humanizer skill:**
   - Remove AI-sounding phrases
   - Add personality and voice
   - Vary sentence structure
   - Include personal anecdotes
   - Fix overly formal tone
2. **Read aloud** - Does it sound natural?
3. **Have someone else read** - Fresh eyes catch AI patterns

### Phase 4: Optimization (30-45 min per article)
1. **SEO elements:**
   - Meta title (50-60 chars, keyword)
   - Meta description (150-160 chars, CTA)
   - H1 = title
   - Target keyword in first paragraph
   - Keywords in 2-3 H2s naturally
   - Internal links (3-5)
   - External links (1-2)
2. **Images:**
   - Find/create 5-8 images
   - Descriptive filenames
   - Alt text with keywords
   - Compress (<200KB)
3. **Schema markup:**
   - FAQ schema (if FAQ section)
   - Article schema
   - Review schema (if applicable)

### Phase 5: Publishing (15-30 min)
1. **Upload to CMS** (WordPress or whatever you use)
2. **Set featured image**
3. **Add categories/tags**
4. **Preview** - Check formatting, images, links
5. **Publish**
6. **Share:**
   - Social media
   - Email newsletter (if you have one)
   - Submit to Google Search Console (request indexing)

**Total time per article:** 4-6 hours (research + write + humanize + optimize + publish)
