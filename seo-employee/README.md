## 🛠️ How It Works

### The Pipeline

```
User Input (URL or Topic)
    ↓
keyword-research: Generate & score keywords
    ↓
seo-analyze: Audit site + find technical issues
    ↓
content-strategy: Cluster keywords + create plan
    ↓
write-article: Research + Write + Humanize + Optimize
    ↓
Output: Ready-to-publish content
```

### Each Skill

**keyword-research:**
1. Generate 20-30 keyword ideas
2. Search Google for each keyword
3. Analyze competition (what's ranking)
4. Score by relevance + opportunity + value
5. Prioritize (quick wins vs long-term)
6. Output organized recommendations

**seo-analyze:**
1. Fetch and parse URL
2. Audit technical SEO (title, meta, headers, etc.)
3. Analyze content quality
4. Trigger keyword research
5. Compare to competitors
6. Generate prioritized fix list

**content-strategy:**
1. Cluster keywords by topic
2. Generate 10-15 ideas per cluster
3. Prioritize by SEO value
4. Suggest content formats
5. Create 3-month publishing calendar
6. Select top 3 for immediate writing

**write-article:**
1. Research topic (analyze top 5 ranking pages)
2. Create outline (better than competitors)
3. Write 1500-2500 words
4. **Humanize** (remove AI patterns) ← SECRET SAUCE
5. Optimize for SEO
6. Add meta tags + internal links
7. Output markdown ready to publish

**full-pipeline:**
- Chains all skills together
- Runs analysis → strategy → writes 3 articles
- Packages everything in organized folder
- Creates implementation checklist

## 🎓 Tips for Best Results

### 1. Start with Competitor Analysis
```
Full pipeline for [competitor URL]
```
Learn from what's already working, then beat it.

### 2. Target Quick Wins First
Look for "Low Competition" keywords in the research output. These get you traffic fast and build authority.

### 3. Publish Consistently
1 article/week minimum. The content strategy gives you a 3-month calendar—follow it.

### 4. Internal Link Everything
Connect related articles together. The content strategy shows you how to build topic clusters.

### 5. Update Top Performers
After 2-3 months, expand your highest-traffic articles with more depth.

### 6. Don't Skip Humanization
It's tempting to publish the first draft. Don't. The humanization step is what separates good content from generic AI content.

## 🐛 Troubleshooting

**Q: Keyword research isn't finding good keywords**
A: Try being more specific with your topic or provide a competitor URL to analyze

**Q: Articles are too generic**
A: The research phase needs better input. Provide more context about your specific angle

**Q: Content still sounds AI-generated**
A: The humanizer should fix this, but you can manually run the humanizer skill again on the output

**Q: SEO analysis shows low scores**
A: Follow the action items in priority order. Start with "Critical" items first

**Q: Full pipeline is taking too long**
A: This is normal (~45-60 min). It's writing 3 complete articles. Individual skills are faster.
