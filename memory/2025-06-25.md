### PKM System Updates (2026-01-26)

**Todoist MCP Server Installed:**
- Package: `@abhiz123/todoist-mcp-server`
- Purpose: Quick mobile capture via Todoist API
- MCP Protocol: Model Context Protocol
- Allows: Create tasks, capture thoughts, integrate with third-party AI tools

**How It Works with ClickUp:**

1. **ClickUp = Primary** - Source of truth for task tracking
   - All projects, lists, priorities managed here
   - Todoist = Quick capture** - Fast capture on mobile
   - One-way sync: Todoist → ClickUp → Obsidian

2. **Capture Flow:**
   - User on phone → "Add task: Call supplier" via Todoist
   - Todoist MCP receives request, creates task in ClickUp
   - Task appears in ClickUp immediately
   - During daily planning/inbox processing:
     - ClickUp task → Obsidian (via `[CU-ID]` link)
     - Todoist task marked complete (one-way sync)

3. **Time Tracking:**
   - ClickUp is your time tracking source
   - All work time logged in ClickUp tasks
   - Todoist is for capture only (no time tracking)

4. **What Todoist MCP CAN Do:**
   ✅ Create tasks instantly (quick capture)
   ✅ Get tasks (read-only)
   ✅ Update task status
   ❌ Cannot do: Recurring tasks (use ClickUp)
   ❌ Cannot do: Set reminders/notifications (use ClickUp)
   ❌ Cannot do: Time blocking (use ClickUp)
   ❌ Cannot do: Bulk operations (use ClickUp)
   ❌ Cannot do: Advanced dependencies (use ClickUp)

5. **What ClickUp STILL Does:**
   ✅ ALL task operations (create, update, complete, delete)
   ✅ ALL project/area management
   ✅ ALL time tracking
   ✅ Recurring tasks
   ✅ Time blocking
   ✅ Smart notifications
   ✅ Rich metadata
   ✅ Bulk operations
   ✅ Workspace templates
   ✅ Advanced dependencies

---

## System Architecture

```
User Input
    ↓
[Quick Capture] Todoist MCP (mobile)
    ↓ Creates in ClickUp (instant)
    ↓ ClickUp API → Obsidian (via [CU-ID])
    ↓ Todoist task marked complete

[Task Planning] ClickUp API (primary)
    ↓ Reads all tasks
    ↓ Generates daily plans
    ↓ Obsidian task links [CU-ID]

[Task Completion] ClickUp API (primary)
    ↓ Work time tracking
    ↓ Mark tasks complete ✅
    ↓ Sync with Obsidian
```
