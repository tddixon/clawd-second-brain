# Keyword Research Skill

AI-powered keyword discovery and prioritization.

## Quick Start

Just say:
- "Do keyword research for [URL]"
- "Find keywords for [topic]"
- "Keyword research: [business/topic]"

## What You Get

- 20-30 relevant keyword ideas
- Competition analysis for each
- Priority rankings (what to target first)
- Quick wins vs long-term plays
- Content gap opportunities
- Actionable implementation plan

## Output Location

Results saved to: `/home/desktop/clawd/seo-employee/output/keyword-research/`

## Examples

```
Do keyword research for https://madmonkeyhostels.com
```

```
Find keywords for Bangkok hostels targeting backpackers
```

```
Keyword research: Chiang Mai accommodation for digital nomads
```
