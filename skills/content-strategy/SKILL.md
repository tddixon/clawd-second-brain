# Content Strategy - Topic Clusters & Content Planning

**Trigger:** "content strategy", "content plan", "content ideas for", "what should I write about"

## What This Does

Transforms keywords into a strategic content plan:
1. **Organizes keywords into topic clusters**
2. **Generates 10-15 content ideas per cluster**
3. **Recommends content formats** (blog, guide, comparison, FAQ)
4. **Prioritizes by SEO value** (traffic potential + competition)
5. **Creates implementation timeline** (what to write when)

## Input Options

Can accept:
- **Keywords list** (comma-separated)
- **URL from seo-analyze** (automatically pulls keywords)
- **Competitor URL** (analyze their content + find gaps)
- **General topic** ("content strategy for Bangkok hostels")

## Process

### Phase 1: Keyword Clustering
Group keywords into logical topics:
- **Topic cluster method:** Group by search intent + theme
- **Example clusters:**
  - "Finding a hostel" (best hostels, hostel guide, how to choose)
  - "Hostel features" (pool, rooftop, private rooms)
  - "Location-specific" (Bangkok, Chiang Mai, by neighborhood)
  - "Traveler types" (solo female, digital nomads, backpackers)

### Phase 2: Content Gap Analysis
For each cluster:
1. Search top keywords in that cluster
2. Analyze what content exists
3. Identify gaps (what's missing or weak)
4. Find unique angles to take

### Phase 3: Content Ideation
Generate 10-15 article ideas per cluster:
- Include headline suggestions
- Specify content type (listicle, guide, comparison, how-to)
- Note target keywords
- Suggest word count
- Indicate priority (quick win vs long-term)

### Phase 4: Prioritization Matrix
Rank content ideas by:
- **SEO Value** (search volume potential)
- **Competition** (how hard to rank)
- **Relevance** (fit with business)
- **Effort** (time to create)

Calculate priority score to recommend what to write first.

### Phase 5: Content Calendar
Create 3-month plan:
- Month 1: Quick wins (low competition, high relevance)
- Month 2: Medium competition keywords
- Month 3: Cluster completion + start next cluster

## Content Formats Guide

### When to Use Each Format

**Listicles** ("Best X", "Top 10 X")
- Use for: Comparison keywords, "best" searches
- Length: 1500-2500 words
- Structure: Intro + 7-10 items + conclusion
- Example: "10 Best Bangkok Hostels for Solo Travelers"

**Comprehensive Guides** ("Ultimate Guide", "Complete Guide")
- Use for: Broad informational keywords
- Length: 2500-4000 words
- Structure: TOC + multiple H2 sections
- Example: "The Ultimate Guide to Bangkok Hostels (2026)"

**Comparison Posts** ("X vs Y", "X or Y")
- Use for: Decision-making keywords
- Length: 2000-3000 words
- Structure: Intro + side-by-side comparison + verdict
- Example: "Khao San Road vs Sukhumvit: Where to Stay in Bangkok"

**How-To Guides**
- Use for: Process/instruction keywords
- Length: 1500-2500 words
- Structure: Intro + numbered steps + tips
- Example: "How to Choose the Right Bangkok Hostel (First-Timer's Guide)"

**Location Pages** (Programmatic SEO)
- Use for: City/neighborhood keywords
- Length: 1500-2000 words
- Structure: Template-based, reusable format
- Example: "Best Hostels in [Neighborhood], Bangkok"

## Content Production Guidelines

### Writing Process
1. Research: Review top 5 ranking pages
2. Outline: Beat competitors' content + add unique insights
3. Write: 1500-2500 words, scannable format
4. Humanize: Run through humanizer skill (mandatory)
5. Optimize: Add meta tags, internal links, images
6. Publish: Upload to CMS

### Content Checklist
- [ ] Target keyword in title, H1, first paragraph
- [ ] 3-5 H2 sections with related keywords
- [ ] 1500-2500 words minimum
- [ ] 3-5 images with descriptive alt text
- [ ] Internal links to 2-3 related articles
- [ ] External links to 1-2 authority sources
- [ ] Meta title (50-60 characters)
- [ ] Meta description (150-160 characters)
- [ ] FAQ section (for featured snippets)
- [ ] CTA (booking link, newsletter signup)
- [ ] Humanized (no AI-sounding phrases)
